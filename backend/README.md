# Backend

Esta pasta contém o código-fonte da API da aplicação.

## Tecnologias previstas

- Spring Boot
- Spring Security
- JPA/Hibernate
- PostgreSQL ou MySQL

## Responsável

Equipe de Back-end.

## Estrutura prevista

Nesta pasta serão desenvolvidos os seguintes componentes:

- Controllers
- Services
- Repositories
- Entidades (Models)
- DTOs
- Segurança (JWT)
- Configurações
- Testes do back-end
