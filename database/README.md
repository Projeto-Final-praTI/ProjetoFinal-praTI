# Banco de Dados

Esta pasta contém todos os arquivos relacionados ao banco de dados da aplicação.

## Tecnologias previstas

- PostgreSQL ou MySQL

## Responsável

Equipe de Banco de Dados.

## Estrutura prevista

Nesta pasta serão armazenados:

- Scripts de criação do banco
- Scripts de inserção de dados
- Modelo lógico
- Modelo físico
- Diagrama Entidade-Relacionamento (DER)
- Scripts de migração
- Backups do banco
