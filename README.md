# Projeto Final +praTI

## 📖 Sobre o Projeto

Este projeto esta sendo desenvolvido como trabalho final da trilha **Dev. Full Stack 2026** da **+praTi & Codifica**.

O objetivo e desenvolver uma aplicacao web utilizando React no front-end, Spring Boot no back-end e PostgreSQL/MySQL como banco de dados, seguindo boas praticas de desenvolvimento, versionamento com Git e metodologias ageis.

## 🚀 Fluxo de Desenvolvimento

- Cada desenvolvedor trabalha em uma branch `feature/...`.
- Nao e permitido desenvolver diretamente na `main`.
- Todas as alteracoes devem ser enviadas atraves de Pull Request.
- A branch `main` permanece protegida.
